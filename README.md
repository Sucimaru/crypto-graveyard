# Crypto Graveyard

A client-side single-page dashboard that catalogs dead, rugged, and abandoned
cryptocurrency tokens as tombstones in a haunting graveyard. Built with Vite +
React + TypeScript + Tailwind CSS. Live market data comes from the free public
Dexscreener API (no API key).

## Scripts

- `npm run dev` — start the Vite dev server.
- `npm run build` — type-check (`tsc`) and build for production.
- `npm run preview` — preview the production build locally.
- `npm run typecheck` — run `tsc --noEmit`.

See `.kiro/specs/crypto-graveyard/` for the requirements, design, and task plan.
